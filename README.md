# 2025-logic-system-kmap
This repository implements a K-map (Karnaugh map) solver — a powerful tool for finding the minimum Sum of Products (SOP) form of Boolean expressions using C++.

The tool allows 2~4 variables of inputs 


```
- k-map.cpp           # main func w/ test cases  
- k-map_submit.cpp    # mian func for online judge
```
The rests are testing files for costom functions
